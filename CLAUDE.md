# minsky

Factored Datathon 2026: LATAM Bank dataset, a synthetic banking dataset for Mexico, Colombia and Argentina (2023-06-17 to 2026-06-17).

## Setup
- Python env managed with uv: `uv sync`, then `uv run jupyter lab`.
- Credentials in `.env` (see `.env.example`); never commit `.env`.
- Data lives in S3 under `data/` (13 tables). Ignore `data_backup_20260831/`.

## Code
- `bank_data.py`: S3 reads (`load_table`, `read_table`, `headers`), caches Parquet in `data/cache/`.
- `data_dictionary.py`: the official data dictionary (columns, types, PKs, NOT NULL, enums, FKs). Single source of truth for silver.
- `quality.py`: checks against the dictionary.
- `ingest_bronze.py`: incremental, verified copy of the organizer CSVs into our bronze zone (with a run manifest).
- `transform/`: dbt-duckdb project. Silver models and `_silver.yml` are generated by `transform/generate_silver.py`: edit the generator or `data_dictionary.py`, never the generated files. Spanish→documented value mappings in `transform/seeds/enum_mappings.csv`.
- `notebooks/`: `explore_bucket` (bucket inventory), `validate_vs_dictionary` (data vs dictionary findings).
- Reference docs: `kickoff_docs/`.

## Pipeline (`make pipeline`)
1. `make bronze` (incremental): organizer S3 → `s3://<own bucket>/bronze` (byte-identical, run manifest in `bronze/_manifest/`).
2. `make mirror` (incremental): bronze → `data/bronze` (dbt reads local files; reading 1k small files from S3 is minutes per table).
3. `make silver`: full rebuild (~90 s): dbt build → `data/warehouse.duckdb` + Parquet in `data/lake/silver` (facts partitioned by year/month).
4. `make publish` (incremental): `data/lake/silver` → `s3://<own bucket>/silver`.
- Own bucket and AWS profile come from `BRONZE_URI` / `BRONZE_AWS_PROFILE` in `.env`; the organizer keys in `.env` are read-only and only used to read the source.
- Silver test policy: error = what silver guarantees (PK, casts); warn = source issues vs the dictionary, also flagged per row in `_dq_issues`.
- `digital_events` is not in silver yet (see `SKIP` in the generator).

## Data gotchas
Full list with numbers and handling: `docs/known_issues.md` (keep it updated when a new issue is found).
- CSVs have a UTF-8 BOM: read with `encoding="utf-8-sig"`.
- Many categorical values are in Spanish, not the English listed in the dictionary.
- `customers.registration_branch_id` and `service_agents.assigned_branch_id` do not join to `branches`.
- `products.product_number` (6) and `service_agents.employee_code` (13) have duplicates despite being documented unique.
- `transaction_country` mixes `Mexico` and `México` (normalized in silver).
- `process_date` day cuts at 06:00, not midnight.
- `digital_events` is ~15.6M rows: load only the columns you need.
