# Evaluator bank slice

`bank_slice.sql.gz` is a minimal, **synthetic** `bank.*` load for local judge runs
(`compose.evaluator.yaml` → Postgres init, on an empty volume). Regenerated by the team:

```bash
make evaluator-pack        # synthetic rows: the files that are committed
```

It also rewrites `.env.evaluator.example` (sessions + cheat sheet). The routes in the slice come from the
backend policy (`minsky_api.policy.disputes.decide`), so the generator fails if a row stops matching its rule.
`--expires <ISO timestamp>` changes the credential expiry (default 2026-10-17, after the demo window).

The committed files never contain organizer rows. To try the same stack on real gold rows:

```bash
make evaluator-pack-gold   # needs `make gold`; writes bank_slice.gold.sql.gz + .env.evaluator.gold (git-ignored)
EVALUATOR_SLICE=./data/evaluator/bank_slice.gold.sql.gz docker compose -f compose.yaml -f compose.evaluator.yaml up --build
```
