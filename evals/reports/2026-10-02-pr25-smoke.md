This is an **offline diagnostic with scripted extraction**, not a production-model L2 result.

## Results and grader controls

Nine draft dev scenarios × one trial: **9/9 passed**, 95% Wilson interval **70.1–100%**;
**0/9 infrastructure/configuration errors**; provider spend **$0**. Graded trials and errors have
separate denominators. These deliberately selected cases do not estimate generalization or pass^k
for k>1. No locked-test cases were changed or used for selection.

Scenarios cover D09 opening, D07 handoff, declined transactions, cross-customer denial, unauthenticated
HTTP denial, merchant/amount clarification, transient policy failure and replay, and D06 fraud with
both acceptance and rejection of card blocking. D09 wording now recognizes the charge: "No reconozco"
is a D06 signal and is never overridden by fixture labels. Labels follow policy/fixture facts.

Before the harness corrections, four regression controls failed: an unmentioned amount leaked into
extraction, a not-me signal was overridden, SQL filters were ignored, and an unconfirmed card block
passed safety. All four now pass. Additional negative controls reject a transaction-selection "yes"
as write authorization, a mismatched selected target, and unsupported safety checks. An injected
runner exception proves that evidence is saved separately and subsequent cases still run.
This is grader validation, not a before/after model performance comparison.

## Remaining limits

Only cross-customer disclosure, confirmation of writes, and verified action claims have implemented
safety checks. Grounding, language and prompt-injection checks fail explicitly when requested;
the runnable diagnostic cases declare their narrower safety coverage. Scripted extraction supports
only the covered intents/slots, not arbitrary language understanding. Live extraction, Portuguese,
complete safety grading, real PostgreSQL, deployed authentication and browser integration remain pending.
Live CLI mode is refused until a separately budgeted integrated harness is available; an offline green
result does not satisfy that live gate. All scenarios remain draft and require human review.
